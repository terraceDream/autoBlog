# 설명형 블로그 작성 방식과 이미지 운영

조사일: 2026-09-09. 목표는 보고서 같은 글을 독자에게 풀어 설명하는 정보형 블로그로 바꾸는 것이다.

## 조사 대상과 선정 근거

[티스토리 홈](https://www.tistory.com/)의 **인기글 베스트**에서 당시 1·3·5번으로 노출된 글 세 편을 읽었다. 이는 조회 시점의 인기글 목록이며, 장기 방문자·매출·검색 순위가 검증된 블로그 순위는 아니다. 인기와 특정 문체의 인과관계도 입증하지 않았다. 아래는 글 구성에 대한 편집적 관찰이며, 글 속 의료·법률·상품 정보의 정확성을 검증한 자료는 아니다.

## 적용된 양식

실행 지침: `backend/src/main/resources/editorial-guide.md`.
`DraftService`가 파일을 읽고 원문과 디렉션을 붙여 새 초안을 생성한다. 디렉션을 비워도 기본 설명형 문체가 적용된다. 기존 초안은 자동 변경하지 않으며 같은 소재에서 새로 작성하면 적용된다. 지침 파일 수정 후에는 백엔드 재시작/재빌드가 필요하다.

- 도입: 실제 독자가 궁금할 상황 → 첫 두 문단 안에 핵심 답.
- 본문: 배경 → 변화 2~4개 → 쉬운 풀이 → 근거 있는 예시 → 독자에게 미치는 영향.
- 문체: 담백한 합니다·입니다체. 쉬운 설명과 예시로 읽기 편하게 쓰고, 캡션·출처는 짧고 간결하게. 가짜 체험·과장·상투어 제외.
- 소제목: 독자가 묻는 질문 또는 알고 싶은 답. 모든 소제목을 질문으로 강제하지 않음.
- 마무리: 판단 기준과 다음 행동. 의미 없는 반복 요약 제외.
- 시각 자료: 본문과 연결되는 화면·비교·절차 이미지 1~3개 제안. 기획은 checks에 표시하고 URL을 AI가 만들지 않음.

### 문체 예시 (가상 기능 설명, 실제 제품 정보 아님)

전: “예약 수집 기능은 사용자가 지정한 주기에 따라 외부 콘텐츠를 수집하며 실행 결과의 영속성을 보장합니다.”

후: “매번 새 글이 올라왔는지 확인하기 번거롭다면 예약 수집을 설정해 보세요. 정해 둔 시간에 새 자료를 모으고 실행 기록도 남깁니다. 수집하려면 프로그램이 실행 중이어야 합니다.”

핵심은 친근한 종결어미만 붙이는 것이 아니라, 기능 설명을 독자의 상황과 실제 조건으로 바꾸는 것이다.

## 이미지 사용 방법 (자동 배치 업데이트)

새 초안은 Commons에서 라이선스 메타데이터를 확인한 후보를 모델에 전달하고, 모델이 이미지 ID·캡션·문단 위치를 반환하면 서버가 실제 이미지를 삽입한다. 기본 최대 3개이며, 관련 없는 후보는 선택하지 않는다. 검색 실패/후보 없음은 checks에 표시한다. 표는 인라인 서식을 포함하는 실제 HTML로 렌더링한다. 기존 초안은 자동으로 다시 쓰지 않으며 새로 작성해야 자동 이미지가 적용된다.


1. 새 초안의 이미지 제안에서 필요한 내용을 확인한다.
2. 원문에서 추출된 후보의 출처 페이지를 열거나 Wikimedia Commons 검색 링크로 관련 이미지를 찾는다. 후보 목록은 재사용 허가 목록이 아니다.
3. 사용할 이미지 HTTPS 주소, 제작자, 출처 페이지, 라이선스/허락 이름과 근거 링크, 설명을 입력한다. 최대 3개.
4. 이 블로그에서의 사용(수익화 여부 포함), 외부 삽입 조건을 실제 확인한 뒤 확인란을 선택한다. 직접 제작도 공개된 자산·권리 안내 페이지를 근거로 남길 수 있다.
5. 삽입 위치를 문단 번호로 지정하고 저장한다. 0은 맨 위, 본문보다 큰 번호는 마지막 문단 뒤다.
6. 저장된 미리보기에서 이미지·캡션·출처를 확인한다. 티스토리 전송 시에도 동일한 구성을 사용하며 이미지 로딩 실패 시 저장 전에 중단한다.

현재 구현은 **외부 이미지 URL 삽입**이다. 이미지 파일을 티스토리 저장소에 업로드하는 기능, 이미지 생성은 포함하지 않는다. 자동 검색은 Commons API를 사용하며 메타데이터를 필터링하지만 권리 관계 전체를 보증하지는 않는다. 외부 서버가 삭제·차단하면 이미지가 표시되지 않을 수 있다. 원문 후보는 article/main의 img에서 최대 6개를 추출하며 동적 이미지·srcset 전용 이미지는 누락될 수 있다.

### 사용 조건을 판단할 근거

[Wikimedia Commons 재사용 안내](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)는 파일마다 저작자와 라이선스 조건을 확인하도록 안내한다. [Creative Commons 재사용 안내](https://creativecommons.org/reusing-cc-licensed-content/)는 사용한 라이선스와 적절한 저작자 표시를 요구한다. 공통적으로 출처 링크만 붙이는 것이 모든 사용 허가를 대신하지 않는다.

공개 라이선스라도 상업적 사용, 변경 여부, 동일조건변경허락 등 실제 조건에 맞춰 사용한다. 공식 보도자료 이미지도 개별 재사용 조건을 확인한다. 허가가 없는 기사 사진은 직접 만든 도식이나 사용 가능한 대체 이미지로 교체한다.

## 검토 기준

실제 글 3~5편을 생성한 뒤 도입의 명확성, 용어 풀이, 근거·예시 구분, 반복 문장, 이미지의 설명 기여를 비교한다. 한 번에 한두 가지 규칙만 조정한다. 테스트 통과는 문체 품질이나 검색 상위 노출을 보장하지 않는다.
