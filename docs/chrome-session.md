# 이미 로그인된 Chrome으로 연결하기

별도 Chrome 실행과 로그인 쿠키 복사 방식을 없앴습니다. 현재 사용하는 Chrome에 확장 프로그램을 최초 한 번 설치하면 그 프로필의 로그인 상태를 그대로 사용합니다.

1. Issue Desk 서버를 실행합니다.
2. **티스토리에 로그인되어 있는 Chrome**에서 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 아래 폴더를 선택합니다.

   `C:\project\workspace\autoBlog\.tools\tistory-chrome-extension`

5. Chrome 확장 메뉴에서 **Issue Desk · 기존 Chrome 연결** 아이콘을 눌러 `ON`을 확인합니다.
6. 앱에서 **기존 Chrome 세션 연결됨**을 확인한 뒤 글을 전송합니다. 자동 연결 상태 갱신은 약 30초 주기이며 아이콘을 누르면 바로 확인합니다.

다음 글도 같은 Chrome 프로필에서 작성됩니다. 기존 글을 덮어쓰지 않도록 작성 탭만 추가하고, 저장 후 탭과 창은 닫지 않습니다. 티스토리 로그인 자체가 만료되면 기존 Chrome에서 로그인하면 됩니다. 여러 Chrome 프로필을 사용하는 경우 반드시 로그인된 프로필에 설치하세요.

코드를 업데이트한 뒤에는 확장 관리 페이지에서 이 확장의 새로고침 버튼을 누릅니다. 서버 재시작만으로 설치된 확장 코드가 다시 로드되지는 않습니다.

## 연결 범위

확장은 localhost의 Issue Desk와 티스토리 페이지에 접근합니다. 쿠키 읽기·디버거·전체 사이트 접근 권한은 요청하지 않습니다. 로그인 비밀번호나 쿠키를 앱에 복사하지 않습니다. 로컬 연결 키가 포함된 생성 폴더는 `.tools` 아래 Git 제외 대상입니다.

Chrome이 닫혔거나 확장이 꺼져 있으면 앱은 새로운 브라우저를 띄우지 않습니다. 전송 시작 전 연결 오류는 초안을 유지하고, 전송 도중 중단된 작업은 자동 재실행하지 않습니다. 비공개 선택 및 결과 확인 실패 시 열린 탭을 직접 확인하세요.

확장 방식의 실제 티스토리 편집기 호환성은 설치 후 확인이 필요합니다. 카테고리·본문·이미지 또는 비공개 상태를 확인하지 못하면 자동 저장을 중단합니다.

공식 설치 절차: [Chrome 확장 프로그램 로컬 로드 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked).
# 새 글과 실패한 전송 재시도

확장 버전 1.2.0부터 자동으로 연 새 글 탭은 임시글 이어쓰기를 취소합니다. 일반적으로 직접 연 티스토리 탭의 확인창은 변경하지 않습니다. 업데이트 후 Chrome 확장 관리에서 Issue Desk를 새로고침하세요.

저장 전 실패(`EDITOR_READY`)는 같은 초안을 수정한 뒤 다시 전송할 수 있습니다. 저장 여부가 불확실한 경우(`UNKNOWN`)에는 티스토리 글 목록을 확인하고 ‘저장되지 않았음을 확인했어요 · 기존 초안으로 재시도’를 누르세요. 새 초안을 생성할 필요가 없습니다. 이미 비공개 저장이 확인된 글과 전송 중인 글은 재전송하지 않습니다.
