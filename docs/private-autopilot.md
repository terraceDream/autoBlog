# 버튼 한 번으로 티스토리 비공개 저장

추천 작업실 상단에서 저장할 블로그를 확인하고 **수집부터 TOP 5 비공개 저장**을 누릅니다.

1. 키워드 기반 출처를 연결하고 자료를 수집합니다.
2. 미분류 자료 최대 30건을 15건씩 요약·분류합니다. 기존 분류는 재사용합니다.
3. 1·2티어 상위 후보 최대 5건(자동 선택 시 도메인당 최대 2건)의 원문을 확보해 집중 분석합니다.
4. 원문 근거가 충분한 RECOMMEND 소재를 우선순위대로 최대 5개 작성합니다. HOLD/SKIP은 작성하지 않습니다.
5. 현재 블로그 카테고리로 맞춘 뒤 기존 Chrome 확장으로 순서대로 **비공개 저장**합니다.

서버는 원문 수집·분석·글 작성을 담당합니다. 티스토리 저장에는 연결된 Chrome이 필요하므로 로그인된 Chrome과 Issue Desk 확장을 켜 두어야 합니다. 새로운 브라우저 프로필을 생성하거나 기존 탭을 닫지 않습니다. 공개 전환은 자동 실행하지 않습니다.

## 진행 상태 및 복구

- 실행·단계·분석 ID·글별 연결 정보를 DB에 저장하므로 화면을 새로 고쳐도 진행을 확인할 수 있습니다.
- 이중 클릭은 같은 진행 중 실행을 반환합니다. 동시 자동 실행은 한 개로 제한합니다.
- 자동 실행 항목 ID를 blog_drafts에 UNIQUE로 저장합니다. 같은 항목에 대해 create를 다시 호출해도 기존 초안 ID를 반환합니다.
- SAVED_PRIVATE는 다시 전송하지 않습니다. UNKNOWN은 자동 재전송하지 않고 실행을 PAUSED로 멈춥니다.
- UNKNOWN의 경우 티스토리 글 목록에서 확인한 뒤 기존 초안의 저장 확인/재시도 흐름으로 처리합니다. 무조건 ‘이어 실행’만 눌러도 다시 보내지 않습니다.
- EDITOR_READY는 저장 버튼을 누르기 전의 실패입니다. 로그인/카테고리 문제를 해결하고 이어 실행하면 기존 초안을 재사용합니다.
- 서버 재시작 시 진행 중 실행은 PAUSED가 됩니다. 사용자 재개 전에는 자동으로 전송하지 않습니다.
- 원문 부족이나 그룹화 결과에 따라 5개보다 적을 수 있습니다. 개별 작성 실패는 결과에 남기고 나머지 글은 계속 처리합니다.

## 검증

자동 테스트로 5개 비공개 저장 흐름, 카테고리 매핑, 연결 해제 시 수집 전 중단, 중복 시작 재사용, UNKNOWN 재개 시 재전송 금지, 저장 완료 글을 건너뛴 후 나머지 진행을 확인합니다. Chrome 확장의 비공개 체크/저장 확인 및 탭 유지 흐름은 기존 연동을 사용합니다.
