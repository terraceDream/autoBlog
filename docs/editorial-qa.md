# 추천 작업실 실제 QA 기록 — 2026-09-10

## 검증 기준
URL을 일일이 입력하지 않고 발견→수집→추천에 도달한다. 추천은 독자의 구체적인 질문에 연결되며, 근거 없는 인기도 예측을 하지 않는다. 원문 전체를 확인한 뒤 초안은 필요한 설명만 선별한다. 사용자에게 실패와 재시도 경로가 보여야 한다.

## 반복 1: 실제 발견과 기획
- 기존 분야의 출처 6개에 키워드 검색을 연결해 새로운 원문 86건을 발견했다. 기존 자료 180건에서 266건으로 증가했다.
- 관련 후보 51건 중 도메인당 3건 이하로 10건을 선정했다.
- 실제 추천·댓글 수를 기록하고 원문 링크를 보존했다. 높은 관심을 받은 브랜드 논란과 원문을 확보하지 못한 제품 소개는 AI가 제외했다.
- 수집 일부 실패(LangChain 기존 RSS)는 유지된 실패 상태와 출처별 이유로 표시한다. 전체 성공처럼 숨기지 않는다.
- 발견한 결함: 피드 앞부분만으로 기획하면 본문의 측정 결과를 놓쳐 유용한 비교 소재를 보류했다.

## 반복 2: 전체 원문 기반 기획
- 공개 원문 8건을 포함한 113,154자를 절단 없이 전달했다. 접근하지 못한 나머지는 발췌 자료로 구분했다.
- 추천은 3개: AgentCore 배포 전 평가, Geiger 권한 목록 점검, SageMaker G7 비용·성능 비교.
- 앞선 검토에서 보류한 G7 비교가 전체 측정 조건과 수치를 확인한 뒤 추천으로 바뀌었다. 자체 홍보나 단일 경험 중심 자료는 보류로 내려갔다.
- 한국어 검색어의 일부 기술 용어를 영문 검색어로 정규화하고 중복 자동 검색을 비활성화했다.
- 관심 없는 소재를 숨겨 다음 추천에서 제외하고, 기존 수집 결과에서 복원하도록 연결했다.

## 반복 3: 실제 글 편집
- 첫 초안은 전체 원문 28,261자를 참고해 작성됐으며 실제 HTML 표와 이미지가 포함됐다.
- 발견한 결함: 내부 API 형식·빌드 아키텍처 등 주변 설명이 과도했고 불가리아어 도식이 선택됐다.
- 수정: 독자의 판단 2~3개 중심 구성, 필요한 약어의 첫 등장 설명, 요청하지 않은 구현 세부 생략, 한국어·영어 외 표기 도식 후보 제외, 본문 맥락에 맞는 이미지 검색과 무관한 장식 이미지 제외.
- 수정 후 기본 설정으로 다시 생성한 글은 「AgentCore PR 평가, 품질 통과와 권한 검증을 나누는 기준」이다. 약어를 풀어 설명하고, 인증 방식 비교와 품질·권한을 별도로 검증해야 하는 이유, 실제 도입 시 판단 기준을 담았다. 공급자의 사례와 작성자의 적용 예시도 구분했다.
- 최신 초안을 작업실에서 다시 열어 미리보기의 실제 4열·4행 HTML 표와 셀 테두리를 확인했다. 이번 글은 직접 관련된 사용 가능 이미지를 찾지 못해 이미지를 넣지 않았고, 점검 항목에 이유를 남겼다.
- 새 추천이 갱신돼도 열어 둔 기획·초안을 보존하고, 기획 버튼은 해당 영역으로 스크롤한다. 동시 AI 작업은 초안 생성 전에 거절하며 기존 초안을 잃지 않는다.

## 검증 범위와 후속 기준
- 백엔드 테스트는 자동 출처 중복 방지, 신호 보존, 숨김·오래된 자료·부분문자열 오탐 제외, 한 번의 실행으로 수집→분석 연결, 저장 검증과 기존 동작을 포함한다.
- 백엔드 검증 결과는 39개 통과, 별도 실행이 필요한 Codex 스모크 테스트 1개 건너뜀이다. 실제 Codex 분석·초안 생성은 위 수동 QA에서 별도로 성공했다. 최종 프런트엔드 빌드도 통과했다.
- UI에서는 첫 진입, 수집 실행, 추천 3개, 근거·보류 이유, 작성 진입과 실제 초안 생성을 확인했다. 좁은 화면에서도 카드가 한 열로 배치됐다.
- 공개 게시나 실사용 클릭률 측정은 수행하지 않았다. HN 반응은 해당 커뮤니티의 관측값이며 한국 검색 수요를 의미하지 않는다.
- 기술 분야 밖의 발견 채널 확대와 YouTube 자막 확보는 별도 개선 대상이다. 현재 YouTube는 키가 있을 때 채널 지정 없이 메타데이터 검색까지 지원한다.
- 다음 개선은 숨김 피드백과 실제 게시 결과를 누적해 추천 기준을 조정하는 것이다. 성과 데이터 없이 클릭률이 개선됐다고 판단하지 않는다.
