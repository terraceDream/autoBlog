# 네이버 블로그용 복사·다운로드

기존 초안 화면의 **네이버 블로그용 복사·다운로드**에서 저장된 원고를 재사용합니다. 티스토리 자동 작성·비공개 저장과 별개의 내보내기 기능입니다. AI를 다시 호출하거나 초안의 발행 상태를 변경하지 않습니다.

## 사용 순서

1. 초안을 수정했다면 기존 **초안 수정 저장**으로 저장합니다. 내보내기는 현재 서버에 저장된 버전을 기준으로 합니다.
2. 네이버용 패널을 열고 제목을 복사합니다.
3. 본문 글자 크기·소제목 크기·줄 간격을 선택하고 본문을 서식과 함께 복사해 네이버 글쓰기 화면에 붙여 넣습니다.
4. 이미지는 다운로드하여 본문의 이미지 위치 표시에 맞춰 네이버 사진 도구로 올립니다. 캡션과 제작자·사용 조건·출처도 함께 옮깁니다.
5. 카테고리와 태그를 입력하고, 네이버에서 비공개로 저장한 뒤 확인합니다.

서식을 포함한 본문 복사는 HTML과 일반 텍스트를 함께 클립보드에 넣습니다. 외부 이미지가 포함된 본문을 복사하는 방식도 선택할 수 있으나, 네이버에서 이미지나 서식이 그대로 보존되는 것은 보장되지 않습니다. 기본 이미지 위치 표시와 파일 업로드 방식이 원본 이미지의 외부 링크에 덜 의존합니다.

## 글·표·이미지

- 본문은 실제 HTML 표 구조를 유지합니다. 네이버에서 표가 달라지면 표별 복사 기능을 사용하거나 탭으로 구분된 값을 네이버 표에 옮깁니다.
- 본문 하단의 원문 참고 링크와 이미지 출처·라이선스는 내보내기에 포함됩니다.
- 저장된 이미지 중 재사용 조건이 확인된 이미지에만 다운로드가 제공됩니다. 자동으로 관련 이미지를 추가 생성하지 않습니다.
- 이미지 다운로드는 저장된 주소에 한정하며 기존 공개 인터넷 주소 검증과 용량 제한을 적용합니다. 지원 이미지 파일인지 확인한 후 반환합니다.
- ZIP은 본문과 이미지, 안내 파일을 함께 담습니다. 이미지 다운로드가 실패하면 ZIP 안의 안내·결과 파일에 실패를 기록합니다. 이미지가 누락된 묶음을 모두 성공한 것처럼 표시하지 않습니다.
- 복사 권한이 거부되면 텍스트 복사 또는 화면에서 선택해 복사하는 방법을 이용할 수 있습니다.

## 기존 기능과의 관계

기존 티스토리 URL·Chrome 확장·편집기 입력·비공개 저장 경로는 변경하지 않습니다. 네이버 내보내기를 실행해도 `READY`, `EDITOR_READY`, `SAVED_PRIVATE` 등 기존 초안 상태는 그대로 유지됩니다. 네이버 계정 로그인이나 자동 게재는 수행하지 않으며, 복사 완료를 네이버 저장 완료로 기록하지 않습니다.

기존 작성 원문 중복 제외도 그대로 적용됩니다. 같은 글을 네이버로 옮길 때 새 초안을 생성할 필요가 없습니다.

## 검증 범위

백엔드 전체 테스트 68개와 기존 티스토리 브라우저 회귀 테스트 5개를 통과했습니다. 로컬 검증 화면에서 서식 포함 클립보드의 HTML 표·원문 링크·이미지 태그, 글자 크기·줄 간격, 다운로드 오류 후 재시도 상태를 확인했습니다. 실제 네이버 편집기에 붙여 넣은 뒤 저장하는 과정은 검증하지 않았으므로, 최종 이미지 업로드와 서식은 네이버에서 확인해야 합니다.
